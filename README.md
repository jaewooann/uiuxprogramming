# 동네런 러닝 크루

동네 사람들과 함께 달리는 러닝 크루를 소개하고 참가 신청을 받는 웹페이지입니다.

- 배포 주소: https://jaewooann.github.io/uiuxprogramming/

## 구현한 이벤트

- **click**: 크루 안내의 탭 버튼(코스 / 일정 / 준비물)을 누르면 해당 탭의 내용이 보입니다.
- **input**: 이름을 입력할 때마다 글자 수를 확인해서 안내 문구를 바꿉니다.
- **change**: 참가 요일을 선택하면 선택한 요일을 안내 문구로 보여줍니다.
- **submit**: 신청하기 버튼을 누르면 참가 신청 완료 문구를 보여줍니다.

## 화면 변화

- 탭: 선택한 탭 버튼은 보라색으로 채워지고, 해당 탭의 내용만 보입니다.
- 이름 입력
  - 비어 있으면 "이름을 입력해주세요." (빨간색)
  - 1글자면 "이름은 2글자 이상 입력해주세요." (빨간색)
  - 2글자 이상이면 "OOO님, 참가할 요일을 선택해주세요." (보라색)
- 요일 선택: "OO요일 OO 러닝을 선택했어요." (초록색)
- 신청하기 버튼: 이름(2글자 이상)과 요일이 모두 입력되어야 활성화됩니다.
- 신청 완료: 완료 문구(초록색)가 나오고, 버튼은 "신청 완료"로 바뀌며 회색으로 비활성화됩니다. 이름 입력창과 요일 선택도 비활성화됩니다.

## 테스트 결과

개발자 도구에서 화면 너비를 바꿔가며 확인했습니다.

| 화면 너비 | 탭 전환 | 이름 입력 / 요일 선택 / 신청 | 가로 스크롤 |
| --- | --- | --- | --- |
| 1100px | 정상 | 정상 | 없음 |
| 768px | 정상 | 정상 | 없음 |
| 390px | 정상 | 정상 | 없음 |

- 768px 이하에서는 입력창, 선택 상자, 버튼이 세로로 배치되고 화면이 잘리지 않습니다.
- 처음 탭 전환 시 글자가 잠깐 안 보이는 문제가 있어서 탭 버튼의 글자색에도 transition을 추가해 수정했습니다.
