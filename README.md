# 동네런 러닝 크루

동네 사람들과 함께 달리는 러닝 크루를 소개하고, 정기 러닝 참가 신청을 받는 웹페이지입니다.

## 사용자

- 혼자 달리기가 어렵거나 꾸준히 운동할 동료를 찾는 동네 주민
- 달리기를 처음 시작하는 초보 러너

## 서비스 목적

크루의 코스와 일정을 확인하고, 원하는 요일과 페이스 그룹으로 정기 러닝에 참가 신청할 수 있게 합니다.

## 핵심 행동

이름을 입력하고 참가 요일과 페이스 그룹을 선택해서 러닝 참가 신청을 완료합니다.

## 완료 조건

- 이름이 2글자 이상 입력되어 있다.
- 참가 요일과 페이스 그룹이 모두 선택되어 있다.
- 확인 화면에서 신청하기 버튼을 누르면 완료 화면에 "OOO님, OO요일 OO OO 그룹 러닝 신청이 완료됐어요!"가 표시된다.

## 사용자 흐름

참가 신청은 5단계로 진행되고, 화면 위의 진행 표시에서 현재 단계가 보라색으로 표시됩니다.

1. **시작**: 신청 안내를 읽고 `신청 시작하기`를 누른다.
2. **이름 입력**: 이름을 입력하고 `다음`을 누른다.
3. **요일 선택**: 참가 요일과 페이스 그룹을 고르고 `다음`을 누른다.
4. **확인**: 입력한 이름, 요일, 페이스 그룹을 확인하고 `신청하기`를 누른다. 고칠 내용이 있으면 `이전`을 누른다.
5. **완료**: 신청 완료 문구를 확인한다. `다시 신청하기`를 누르면 처음부터 다시 신청할 수 있다.

## 인터랙션 시나리오

| 행동 | 이벤트 | 조건 | 화면 반응 | 다음 상태 |
| --- | --- | --- | --- | --- |
| 신청 시작하기 클릭 | click | - | 이름 입력 화면이 나오고 진행 표시가 '이름 입력'으로 바뀜 | 2단계 |
| 이름 입력 | input | 비어 있음 | "이름을 입력해주세요." (빨간색) | 2단계 유지 |
| 이름 입력 | input | 1글자 | "이름은 2글자 이상 입력해주세요." (빨간색) | 2단계 유지 |
| 이름 입력 | input | 2글자 이상 | "OOO님, 반가워요! 다음 버튼을 눌러주세요." (보라색) | 2단계 유지 |
| 다음 클릭 | click | 이름이 2글자 미만 | "이름 입력칸에 2글자 이상 입력한 뒤 다음 버튼을 눌러주세요." + 입력칸 빨간 테두리 | 2단계 유지 |
| 다음 클릭 | click | 이름이 2글자 이상 | 요일·페이스 선택 화면 | 3단계 |
| 참가 요일 선택 | change | 요일을 고름 | "OO요일 OO 러닝을 선택했어요." (초록색) | 3단계 유지 |
| 페이스 그룹 선택 | change | 그룹을 고름 | "OO 그룹을 선택했어요." (초록색) | 3단계 유지 |
| 다음 클릭 | click | 요일, 그룹 모두 안 고름 | "참가 요일과 페이스 그룹을 모두 선택한 뒤 다음 버튼을 눌러주세요." + 요일 선택 빨간 테두리 | 3단계 유지 |
| 다음 클릭 | click | 요일만 안 고름 | "참가 요일 목록에서 요일을 선택해주세요." + 요일 선택 빨간 테두리 | 3단계 유지 |
| 다음 클릭 | click | 그룹만 안 고름 | "페이스 그룹 중 하나를 선택해주세요." | 3단계 유지 |
| 다음 클릭 | click | 둘 다 고름 | 확인 화면에 이름, 요일, 그룹이 표시됨 | 4단계 |
| 이전 클릭 | click | 2~4단계 | 바로 앞 화면으로 돌아가고, 입력·선택한 값은 그대로 남아 있음 | 이전 단계 |
| 신청하기 클릭 | submit | 확인 단계 | 완료 화면에 "OOO님, OO요일 OO OO 그룹 러닝 신청이 완료됐어요!" 표시 | 5단계 |
| 다시 신청하기 클릭 | click | 완료 단계 | 이름, 요일, 그룹, 안내 문구, 빨간 테두리를 모두 지우고 시작 화면으로 이동 | 1단계 |

기존 기능인 크루 안내 탭(코스 / 일정 / 준비물)도 그대로 동작합니다. 탭을 누르면 선택한 탭이 보라색으로 바뀌고 해당 내용만 보입니다.

## 테스트 결과

개발자 도구에서 화면 너비를 바꿔가며 직접 눌러보고 확인했습니다.

| 테스트 | 결과 |
| --- | --- |
| 이름을 비워두고 다음 클릭 | 넘어가지 않고 안내 문구와 빨간 테두리 표시 |
| 이름 1글자 입력 후 다음 클릭 | 넘어가지 않고 안내 문구 표시 |
| 요일, 그룹 둘 다 안 고르고 다음 클릭 | 넘어가지 않고 안내 문구 표시 |
| 요일만 고르고 다음 클릭 | 넘어가지 않고 "페이스 그룹 중 하나를 선택해주세요." 표시 |
| 3단계에서 이전 → 다시 다음 | 이름과 선택한 요일이 그대로 남아 있음 |
| 확인 화면에서 이전 → 요일, 그룹, 이름 수정 → 다음 | 확인 화면에 수정한 값이 반영됨 |
| 신청하기 클릭 | 완료 화면과 완료 문구 표시 |
| 다시 신청하기 클릭 | 시작 화면으로 이동, 입력·선택·안내 문구·빨간 테두리 모두 초기화 |
| 크루 안내 탭 클릭 | 선택한 탭 내용만 표시 |
