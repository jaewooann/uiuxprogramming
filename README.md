# 동네런 러닝 크루

동네 사람들과 함께 달리는 러닝 크루를 소개하고, 정기 러닝 참가 신청을 받는 웹페이지입니다.

- GitHub 저장소: https://github.com/jaewooann/uiuxprogramming
- 배포 주소: https://jaewooann.github.io/uiuxprogramming/

## 사용자

- 혼자 달리기가 어렵거나 꾸준히 운동할 동료를 찾는 동네 주민
- 달리기를 처음 시작하는 초보 러너

## 서비스 목적

크루의 코스와 일정을 확인하고, 자신에게 맞는 요일과 페이스 그룹으로 정기 러닝에 참가 신청할 수 있게 합니다.

## 핵심 행동

이름을 입력하고 참가 요일과 페이스 그룹을 선택해서 러닝 참가 신청을 완료합니다.

## 완료 조건

- 이름이 2글자 이상 입력되어 있다.
- 참가 요일과 페이스 그룹이 모두 선택되어 있다.
- 확인 화면에서 신청하기 버튼을 누르면 완료 화면에 "OOO님, OO요일 OO OO 그룹 러닝 신청이 완료됐어요!"가 표시된다.

## 사용자 흐름

참가 신청은 5단계로 진행되고, 화면 위의 진행 표시에서 현재 단계가 보라색으로 표시됩니다.

1. **시작**: 신청 안내를 읽고 `신청 시작하기`를 누른다.
2. **이름 입력**: 이름을 입력하고 `다음`을 누른다.
3. **요일 선택**: 참가 요일과 페이스 그룹을 고르고 `다음`을 누른다. 어떤 그룹이 맞을지 모르겠으면 `내 페이스 확인하기`로 추천을 받을 수 있다. (중간고사에서 추가)
4. **확인**: 입력한 이름, 요일, 페이스 그룹, 내 페이스를 확인하고 `신청하기`를 누른다. 고칠 내용이 있으면 `이전`을 누른다.
5. **완료**: 신청 완료 문구를 확인한다. `다시 신청하기`를 누르면 처음부터 다시 신청할 수 있다.

## 중간고사: 새로 추가한 기능

### 내 페이스 확인 → 그룹 추천

평소에 달리는 거리와 걸리는 시간을 입력하면 1km당 페이스를 계산해서 초보 그룹과 중급 그룹 중 맞는 그룹을 추천하고, 버튼 한 번으로 추천 그룹을 선택할 수 있게 했습니다.
계산한 페이스는 확인 화면의 "내 페이스" 항목에 표시됩니다.

### 추가한 이유와 연결 지점

7주차 흐름에서는 3단계에서 페이스 그룹을 직접 골라야 했는데, 달리기를 처음 시작하는 사용자는 자기가 어느 그룹에 맞는지 알기 어렵습니다.
그래서 **3단계(요일 선택) 중간**, 페이스 그룹 선택지 바로 아래에 `어떤 그룹이 맞을지 모르겠다면? 내 페이스 확인하기` 버튼을 두고, 여기서 확인한 결과가 다시 페이스 그룹 선택과 4단계 확인 화면으로 이어지도록 연결했습니다.

### 추천 기준

- 페이스 = 시간(분) ÷ 거리(km)
- 페이스가 1km당 6분 30초 이하이고 거리가 5km 이상이면 **중급 그룹** (중급 그룹 설명: 쉬지 않고 5km)
- 그 외에는 **초보 그룹**
- 거리가 42.195km보다 길거나 페이스가 1km당 3분보다 빠르면 실제 기록으로 보기 어려워서 추천하지 않음 (결과 없음)

### 사용자 행동, 조건, 화면 반응

| 사용자 행동 | 확인할 조건 | 화면 반응 | 다음 행동 |
| --- | --- | --- | --- |
| `내 페이스 확인하기` 클릭 | - | 거리·시간 입력 칸이 있는 페이스 확인 영역이 열림 | 거리와 시간 입력 |
| `페이스 계산하기` 클릭 | 거리나 시간이 비어 있음 | "거리와 시간을 모두 숫자로 입력한 뒤 페이스 계산하기를 눌러주세요." (빨간색) | 빈 칸 입력 후 다시 계산 |
| `페이스 계산하기` 클릭 | 거리나 시간이 0 이하 | "거리와 시간은 0보다 큰 숫자로 입력해주세요." (빨간색) | 값 수정 후 다시 계산 |
| `페이스 계산하기` 클릭 | 42.195km 초과 또는 1km 3분 미만 (결과 없음) | "추천할 수 있는 그룹을 찾지 못했어요. 거리와 시간이 맞는지 다시 확인하거나, 취소하고 그룹을 직접 선택해주세요." (빨간색) | 값 수정 또는 취소 |
| `페이스 계산하기` 클릭 | 정상 값 (성공) | "내 페이스는 1km당 O분 O초예요. OO 그룹을 추천해요." (초록색) + `OO 그룹으로 선택하기` 버튼 표시 | 추천 그룹 선택 |
| 계산 후 거리나 시간 수정 | 이미 추천 결과가 있음 | "입력값이 바뀌었어요. 페이스 계산하기를 다시 눌러주세요." + 추천 버튼 숨김 | 다시 계산 |
| `OO 그룹으로 선택하기` 클릭 | - | 해당 페이스 그룹 라디오가 선택되고 영역이 닫힘. "페이스 확인 결과에 따라 OO 그룹을 선택했어요." | 다음 → 확인 화면 |
| `취소` 클릭 | 선택한 그룹이 없음 | 영역이 닫히고 "페이스 확인을 취소했어요. 페이스 그룹을 직접 선택해주세요." | 그룹 직접 선택 |
| `취소` 클릭 | 이미 그룹을 선택함 | 영역이 닫히고 "페이스 확인을 취소했어요. 선택한 OO 그룹은 그대로 유지돼요." | 다음 |
| 4단계 확인 화면 진입 | 추천 그룹을 선택했는지 | 선택했으면 "내 페이스: 1km당 O분 O초", 아니면 "내 페이스: 확인 안 함" | 신청하기 또는 이전 |
| 이전으로 3단계에 돌아와 다시 열기 | - | 입력했던 거리, 시간, 계산 결과가 그대로 남아 있음 | 수정 또는 다시 계산 |
| `다시 신청하기` 클릭 | - | 페이스 확인 영역이 닫히고 거리, 시간, 결과 문구, 추천 버튼, 내 페이스 값이 모두 초기화됨 | 처음부터 신청 |

### 구현 과정

- **index.html**: 3단계 페이스 그룹 아래에 `내 페이스 확인하기` 버튼과 페이스 확인 영역(거리·시간 입력, 결과 문구, 취소·계산 버튼, 추천 그룹 선택 버튼)을 추가했습니다. 4단계 확인 화면에는 "내 페이스" 항목을 추가했습니다.
- **style.css**: 페이스 확인 영역은 처음에는 숨겨 두고 `.open` 클래스가 붙으면 보이게 했고, 추천 버튼은 결과가 있을 때만 `.show` 클래스로 보이게 했습니다. 입력칸은 최대 너비를 정해서 모바일에서도 잘리지 않게 했습니다.
- **script.js**: 열기·계산·추천 적용·취소 버튼에 click 이벤트를, 거리·시간 입력칸에 input 이벤트를 연결했습니다. 계산할 때 빈 값, 0 이하, 결과 없음 조건을 차례로 확인하고, 통과하면 페이스와 추천 그룹을 화면에 보여줍니다. 추천 그룹을 선택하면 계산한 페이스를 저장해 두었다가 확인 화면에 표시하고, 다시 신청하기를 누르면 같이 초기화합니다.

## 7주차 참가 신청 흐름

### 인터랙션 시나리오

| 행동 | 이벤트 | 조건 | 화면 반응 | 다음 상태 |
| --- | --- | --- | --- | --- |
| 신청 시작하기 클릭 | click | - | 이름 입력 화면이 나오고 진행 표시가 '이름 입력'으로 바뀜 | 2단계 |
| 이름 입력 | input | 비어 있음 | "이름을 입력해주세요." (빨간색) | 2단계 유지 |
| 이름 입력 | input | 1글자 | "이름은 2글자 이상 입력해주세요." (빨간색) | 2단계 유지 |
| 이름 입력 | input | 2글자 이상 | "OOO님, 반가워요! 다음 버튼을 눌러주세요." (보라색) | 2단계 유지 |
| 다음 클릭 | click | 이름이 2글자 미만 | "이름 입력칸에 2글자 이상 입력한 뒤 다음 버튼을 눌러주세요." + 입력칸 빨간 테두리 | 2단계 유지 |
| 다음 클릭 | click | 이름이 2글자 이상 | 요일·페이스 선택 화면 | 3단계 |
| 참가 요일 선택 | change | 요일을 고름 | "OO요일 OO 러닝을 선택했어요." (초록색) | 3단계 유지 |
| 페이스 그룹 선택 | change | 그룹을 고름 | "OO 그룹을 선택했어요." (초록색) | 3단계 유지 |
| 다음 클릭 | click | 요일, 그룹 모두 안 고름 | "참가 요일과 페이스 그룹을 모두 선택한 뒤 다음 버튼을 눌러주세요." + 요일 선택 빨간 테두리 | 3단계 유지 |
| 다음 클릭 | click | 요일만 안 고름 | "참가 요일 목록에서 요일을 선택해주세요." + 요일 선택 빨간 테두리 | 3단계 유지 |
| 다음 클릭 | click | 그룹만 안 고름 | "페이스 그룹 중 하나를 선택해주세요." | 3단계 유지 |
| 다음 클릭 | click | 둘 다 고름 | 확인 화면에 이름, 요일, 그룹, 내 페이스가 표시됨 | 4단계 |
| 이전 클릭 | click | 2~4단계 | 바로 앞 화면으로 돌아가고, 입력·선택한 값은 그대로 남아 있음 | 이전 단계 |
| 신청하기 클릭 | submit | 확인 단계 | 완료 화면에 "OOO님, OO요일 OO OO 그룹 러닝 신청이 완료됐어요!" 표시 | 5단계 |
| 다시 신청하기 클릭 | click | 완료 단계 | 이름, 요일, 그룹, 안내 문구, 빨간 테두리를 모두 지우고 시작 화면으로 이동 | 1단계 |

기존 기능인 크루 안내 탭(코스 / 일정 / 준비물)도 그대로 동작합니다. 탭을 누르면 선택한 탭이 보라색으로 바뀌고 해당 내용만 보입니다.
